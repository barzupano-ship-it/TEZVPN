# SULTAN VPN

Приложение для Google Play и App Store: тариф, оплата, AmneziaWG внутри одного приложения. На экране название SULTAN VPN.

Клиенту отдаётся папка `flutter`. Как собрать AAB для Play и архив для App Store, написано в `flutter/README.md`.

Ключ подписи Android уже внутри этой папки: `flutter/android/app/upload-keystore.jks` и `flutter/android/key.properties`. Их передают вместе с проектом и не публикуют.
